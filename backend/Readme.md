To create the openAi secret key using github free access 
    -> Go to github profile 
    -> settings 
    -> developer settings 
    -> personal access token 
    -> Token(classic)

To get base code for request the openAi 
    -> Go to github MarketPlace (https://github.com/marketplace)
    -> Choose the model that you like
    -> PlayGound
    -> go to Code
    -> choose the language & SDK
